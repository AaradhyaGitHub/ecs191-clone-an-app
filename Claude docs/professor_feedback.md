# Professor feedback on the proposal (Prof. King)

> Overall this app looks great. Parking is a real problem for anyone who visits campus, and you have identified some real issues with the current parking apps. My only concern is around availability of interacting with actual UC Davis parking systems. Is there an API or some other way that you can enable people to purchase parking? If you wanted to just focus on the map aspects that might be more reasonable if a parking API isn't available.

## Response / decision
No public API for AMP Park (AIMS Mobile Pay) was found, so the first cut drops payments entirely and focuses on the map and recommendation side: finding the closest student-eligible lots and handing off to navigation.
